# Excel Retail Sales Dashboard

An interactive Excel dashboard built from the **Global Superstore** retail dataset, covering the full workflow from raw data to a stakeholder-ready summary view.

## File

`Retail_Sales_Analysis_dashboard.xlsx`

## Workbook structure

| Sheet | Purpose |
|-------|---------|
| `Raw Data` | Original, unmodified retail order data |
| `Clean_Data` | Cleaned dataset with corrections and derived fields applied |
| `Analysis` | Summary calculations feeding the dashboard |
| `Sales by Category` | Sales totals broken down by product category |
| `Sales by Month` | Monthly sales trend across the full date range |
| `Sales by Segment` | Sales split by customer segment |
| `Sales by Region` | Regional sales performance |
| `Ship Mode Analysis` | Order volume by shipping method |
| `Top 10 Products` | Best-selling products by total sales |
| `Sales by State` | State-level sales breakdown |
| `Average Shipping Days` | Average delivery time by shipping mode |
| `Dashboard` | Consolidated interactive view pulling from all analysis sheets |

## Skills demonstrated

- Data cleaning (handling raw, inconsistent source data)
- Pivot tables and summary formulas
- Multi-sheet workbook design with a single consolidated dashboard view
- Translating granular transaction data into decision-ready summaries

## How to use

Open the workbook and start on the `Dashboard` sheet for the consolidated view, or explore individual analysis sheets for the underlying breakdowns.
